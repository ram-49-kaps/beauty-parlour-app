## 📋 Step-by-Step Workflow

### Step 1: Generate All 6 Clips
1. Go to [firefly.adobe.com/generate/video](https://firefly.adobe.com/generate/video)
2. Set the settings (Veo 3.1, 720p, 16:9, 24fps, 8s, Audio OFF)
3. For each clip above:
   - Upload the reference image (if specified) under **References → Images → First**
   - Paste the prompt
   - Click **Generate**
   - Download the best result

### Step 2: Download All Clips
- Click **Download** on each generated video
- Name them: `clip1_logo.mp4`, `clip2_offer.mp4`, etc.

### Step 3: Combine in CapCut (Free)
1. Download **CapCut** (free, available on Mac/iPhone)
2. Create new project → **16:9 landscape**
3. Import all 6 clips in order
4. Trim each clip to fit the timeline:
   - Clip 1: 3.5 seconds
   - Clip 2: 4 seconds
   - Clip 3: 3.5 seconds
   - Clip 4: 3.5 seconds
   - Clip 5: 4.5 seconds
   - Clip 6: 3 seconds
5. Add **transitions** between clips (use "Fade" or "Dissolve")
6. Add **background music** (CapCut has free tracks — search "luxury" or "elegant")
7. **Export** as MP4 → 1080p

### Step 4: Post on Instagram
1. Open Instagram → **New Reel**
2. Upload the exported MP4
3. Add hashtags:

## 💡 Pro Tips

| Tip | Why |
|-----|-----|
| Generate 2-3 versions of each clip | Pick the best one |
| Use "First frame" reference, not "Last" | Controls the starting visual |
| Keep prompts under 200 words | Firefly works better with focused prompts |
| If a clip looks weird, add "no text" to prompt | Firefly sometimes generates garbled text |
| For text overlays, add them in CapCut instead | Much cleaner than AI-generated text |

## ⚡ Quick Alternative: Text Overlays in CapCut

If Firefly generates messy text (common with AI video), use this approach:
1. Generate clips **without text** (remove text descriptions from prompts)
2. Add all text overlays in **CapCut** manually:
   - Use **Playfair Display** or **Cormorant Garamond** font (elegant serif)
   - White text, gold accents
   - Fade-in animations
3. This gives you **pixel-perfect** text control
